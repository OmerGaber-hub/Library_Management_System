# 📚 نظام إدارة المكتبة (Library Management System)

![Flutter](https://img.shields.io/badge/Flutter-3.x-blue?style=for-the-badge&logo=flutter)
![Dart](https://img.shields.io/badge/Dart-3.x-0175C2?style=for-the-badge&logo=dart)
![SQLite](https://img.shields.io/badge/SQLite-07405E?style=for-the-badge&logo=sqlite)

تطبيق متكامل مبني باستخدام إطار عمل **Flutter** لإدارة المكتبات وحجز واستعارة الكتب بطريقة ذكية وعصرية. يهدف التطبيق إلى رقمنة وأتمتة العمليات اليومية في المكتبة من خلال توفير واجهات مخصصة لكلٍ من (مدير النظام، أمين المكتبة، والمستعير).

---

## ✨ المميزات الرئيسية

### 👨‍💼 لوحة الإدارة (Admin & Librarian)
- **إدارة شاملة للكتب والنسخ:** إضافة وتعديل وحذف الكتب، وإدارة الفهرس، وإضافة النسخ الفيزيائية وتحديد أماكن رفوفها.
- **إدارة الطلبات:** الموافقة على حجوزات الكتب أو رفضها، وتحويلها إلى استعارات.
- **نظام غرامات ذكي:** فرض غرامات مالية تلقائية عند التأخير في إرجاع الكتب، وإمكانية تسويتها.
- **إدارة المستخدمين:** لوحة تحكم بصلاحيات المستخدمين وترقية الحسابات (للأدمن فقط).
- **إحصائيات (Dashboard):** عرض إجمالي الكتب، المستخدمين، الاستعارات النشطة، والغرامات المعلقة.
- **البيانات الأساسية:** إدارة المؤلفين، التصنيفات، ودور النشر.

### 🧑‍🎓 واجهة المستعير (Borrower)
- **تصفح الفهرس:** استعراض الكتب المتاحة، والبحث عن العناوين بسهولة.
- **الكتب الإلكترونية (PDF):** قراءة الكتب الإلكترونية من داخل التطبيق أو تحميلها مباشرة إلى الجهاز (`Downloads`).
- **حجز الكتب الورقية:** طلب استعارة نسخة فيزيائية من المكتبة لمعرفة توفرها.
- **متابعة النشاط:** تتبع الحجوزات، الاستعارات الحالية، ومواعيد الإرجاع لتجنب الغرامات.

### 🎨 تجربة المستخدم (UI/UX)
- واجهات عصرية ونظيفة مبنية على **Material Design**.
- دعم **الوضع الليلي (Dark Mode)** لراحة العين.
- تصميم متجاوب يعمل بسلاسة على أجهزة الأندرويد.

---

## 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية:** Flutter & Dart.
- **قاعدة البيانات:** `sqflite` (قاعدة بيانات محلية متكاملة بـ 10 جداول مترابطة العلاقات).
- **التخزين الخفيف:** `shared_preferences` (لحفظ التفضيلات كحالة تسجيل الدخول والوضع الليلي).
- **التعامل مع الملفات:** `dart:io` لتحميل وقراءة ملفات الـ PDF.

## 🚀 كيفية التشغيل (Getting Started)

### المتطلبات المسبقة:
- تثبيت [Flutter SDK](https://flutter.dev/docs/get-started/install).
- تثبيت Android Studio أو محاكي أندرويد لعمل Build للتطبيق.

### خطوات التشغيل:
1. قم باستنساخ المستودع (Clone the repository):
   ```bash
   git clone https://github.com/your-username/library_management_system.git
   ```
2. انتقل إلى مجلد المشروع:
   ```bash
   cd library_management_system
   ```
3. قم بتنزيل الحزم والمكتبات المعتمدة:
   ```bash
   flutter pub get
   ```
4. قم بتشغيل التطبيق على المحاكي أو جهازك الحقيقي:
   ```bash
   flutter run
   ```
